# Aadhaar accuracy baseline (extraction `POST /api/v1/extract`)

30 invented cards: 28 with a valid number (scored for accuracy) and 2 whose number has a wrong check digit (own class). Generated by `report.py` from `run.py`; the committed numbers are the baseline. Counts only.

How a field is scored: `correct` the printed value; `wrong` a different value; `empty` no value (or the document was not recognised as an Aadhaar card); `review` sent to a person (NEEDS_REVIEW), with the number of those whose value was right in brackets. The Aadhaar number comes back masked and counts as correct only as exactly `XXXX XXXX` plus the printed last four digits.
