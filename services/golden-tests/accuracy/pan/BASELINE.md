# PAN accuracy baseline (extraction `POST /api/v1/extract`)

100 invented cards, English only: 98 with a valid number (scored for accuracy, 392 fields) and 2 whose number is of the wrong shape (own class, 8 fields, not in the figures below). Generated by `report.py` from `run.py`; the committed numbers are the baseline.

How a field is scored: **Correct** the printed value, ignoring case, spacing and punctuation (dates in any format). **Exact** the value is the printed text character for character. **Wrong ACCEPTED** a different value marked ACCEPTED: nobody will check it, so this is the number that matters most. **Wrong NEEDS_REVIEW** a different value a person will see. **Missing** no value. **Review rate** the share of fields marked NEEDS_REVIEW, right or wrong.
