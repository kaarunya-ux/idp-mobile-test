- dob: the line labelled DOB, as DD/MM/YYYY exactly as printed.
- gender: the English word printed after dob; answer M, F or O.

- pincode: the 6-digit PIN code at the end of the address; null when address_visible is false.

Rules: copy every value character for character. If a value is unreadable use null, never guess. Output JSON only.
